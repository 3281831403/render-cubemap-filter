# render-cubemap-filter

## 题面

环境光换成预滤波立方体后，粗糙面还是镜面、接缝处一条亮线：方向不归一，面归属错；纹素立体角按平面像素面积算，mip 偏小；mip 选择向下取整，粗糙面依旧锐利；GGX 采样不随粗糙度变化，全都采成镜面方向；逐纹素滤波不按样本数归一，亮度随采样数漂移；面边缘重复纹素，接缝处出现亮线；面数不为 6 不报错，缺面直接全黑；各面尺寸不等不校验，采样越界；批量预滤波共用输出面，批次之间互相串扰；samples=0 不校验，直接除零。cubemap/prefilter.py 是核心，tests/test_prefilter.py 15个红。要修的是：方向先归一化再按主轴选面并计算 uv；按立方体 4π 总立体角均分到 6 个面和 N² 个纹素计算单纹素立体角；粗糙度到 mip 的映射向上取整并夹紧到合法范围；GGX 重要性采样随粗糙度改变半程向量并保持单位长度；逐纹素滤波按样本数取平均，让亮度与采样数无关；按立方体棱上的同一点对齐边界纹素，消除接缝亮线；补全面数、尺寸与 NaN 校验，并在采样前拒绝 samples=0；批量先整体校验再计算，输出面逐项独立、任一非法整体回滚。

## 运行方式

在仓库根目录执行：

```powershell
python -m pytest tests -q
```

初始失败基线的输出尾部应为：

```text
15 failed in 0.11s
```

即恰好 `15 failed`，且不得出现 collection error、import error 或 syntax error。修复全部缺陷后应为 `15 passed`。测试只依赖 Python 标准库与 pytest，可离线运行。

## tests 不可修改

`tests/test_prefilter.py` 是验收用例，不可修改、删除、跳过或放宽断言；只应修改 `cubemap/prefilter.py`。不得引入第三方依赖、不得联网，也不得使用随机数破坏采样序列的确定性。
